# Ayanami

Аянами-Ассистент

Голосовой ассистент Аянами - это полностью автономный виртуальный помощник. Ассистент распознаёт голосовые команды, отвечает голосом, управляет музыкой пауза/продолжить/переключение треков, регулирует громкость, показывает время и дату. Не требует подключения к интернету.

Аянами Ассистент - это десктопное приложение для Windows, которое позволяет управлять компьютером с помощью голоса. Ассистент предназначен для удобного голосового управления мультимедиа.

Основные возможности: Голосовое распознавание - ассистент слышит и понимает голосовые команды Голосовые ответы - ассистент отвечает чистым женским голосом Управление музыкой - пауза, продолжение, следующий/предыдущий трек Управление громкостью - увеличение и уменьшение громкости Текущее время и дата - голосовой ответ о времени и дате Анимированный аватар - окно с аватаром, которое можно перетаскивать мышкой Дружелюбное общение - ассистент реагирует на похвалу и благодарности

Язык программирования C++17 Распознавание речи Vosk API Синтез речи Microsoft SAPI 5 Графический интерфейс Win32 API + GDI Захват звука Windows Core Audio Сборка Visual Studio 2022

Требования Windows 10/11 (64-bit) Микрофон Установленный русский голос для SAPI 5 (встроен в Windows)

Запуск Скачайте последний релиз Распакуйте архив в любую папку Запустите Ayanami.exe Скажите Привет (ассистент активируется)

Необходимое ПО для сборки из исходников Visual Studio 2022 (Community Edition) Компоненты: Разработка классических приложений C++
